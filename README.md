# Take It Out

## 게임 소개

학교에서 일어나는 수상한 사건을 일주일 동안 조사하는 스토리 중심의 어드벤처 게임입니다.

플레이어는 인물들과 대화하고 단서를 조사하며 사건을 추적합니다.

선물과 대화 선택지에 따라 인물별 호감도가 달라지며, 호감도와 진행 조건에 따라 데스 엔딩을 포함한 여러 엔딩으로 이어지도록 기획했습니다.

## 제작 방식 및 본인 역할

개발 도구: Unity, Fungus

제작 인원: 1인

개인 프로젝트로 게임의 이야기와 진행 흐름을 기획하고, Fungus를 활용해 대사와 조건별 분기를 구성했습니다.

C# 코드는 ChatGPT를 활용해 생성·수정했으며, Unity에서 적용 및 설정을 진행했습니다.

직접 플레이하며 오류 발생 상황과 수정 방향을 정리하고, 수정 후 정상 작동 여부와 다른 기능에 미치는 영향을 확인했습니다.

## 주요 기능

인물과의 대화에서 선택지를 제공하며, 선택에 따라 호감도가 달라지도록 구성했습니다.

## 현재 제작 상태

현재 4일차 중반까지 플레이 가능한 내용을 구현했습니다. 이후 스토리와 엔딩은 제작 중입니다.

## 문제 해결 경험

### 1. 배경 전환 후 버튼 잠금이 풀리는 문제

대사·연출 중 배경이 전환되면 버튼 잠금이 풀려, 사용할 수 없어야 하는 버튼이 눌리는 문제를 발견했습니다.

기존 잠금 상태를 유지하도록 수정 방향을 정리하고, 연출용 클릭 차단과 대사·UI 잠금을 분리하는 방식으로 개선했습니다.

코드 수정에는 ChatGPT를 활용했으며, 수정 후 동일 상황을 반복 실행하고 다른 기능에 미치는 영향도 확인했습니다.

### 2. 장소 이동 시 스토리 조건이 적용되지 않는 문제

특정 장소로 이동했을 때 조건에 맞는 스토리가 실행되지 않는 문제를 발견했습니다.

버튼의 OnClick 연결을 확인한 결과, 조건을 검사하는 기능 대신 장소를 바로 전환하는 기능이 연결되어 있었습니다.

조건을 확인한 뒤 스토리 실행 또는 장소 이동이 이루어지도록 연결을 수정했습니다.

수정 후 조건 충족 여부에 따라 스토리와 장소 이동이 정상적으로 실행되는지 확인했습니다.
